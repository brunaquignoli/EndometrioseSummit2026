# Endometriose Summit UMC 2026
O método utilizado foi o modelo de aprendizado de máquina Máquina de Vetores de Suporte (SVM). O tipo de análise consistiu no treinamento do algoritmo com ajuste do parâmetro de regularização por validação cruzada, avaliando o desempenho por acurácia, precisão, revocação, F1-score e matriz de confusão. Os resultados demonstraram a capacidade do modelo em classificar as pacientes de forma binária com eficiência, sendo ela O para ausência e 1 para presença da doença crônica, apresentando a viabilidade de utilizar variáveis de identificação não invasivas para estruturar o risco da patologia. Conclui-se que o modelo atende ao objetivo preditivo e é uma ferramenta viável para a identificação da endometriose, auxiliando no rastreio inicial de mulheres com maior risco, destacando o potencial do uso de informações clínicas de fácil obtenção para apoiar a investigação diagnóstica precoce e ampliar o acesso à avaliação especializada.
